# NOVA_UI_AUDIT_REPORT

## Scope and evidence

Preview 4.0; authoritative package `Nova_Codex_Handover_2026-09-17_4.0_FINAL(1).zip`. The written specification takes precedence over illustrative labels. This is a recursive **source/route audit plus bounded rendered/emulator checks**, not a claim that every route was exercised on a Shield. The implementation continues from delivered Preview 3.9 commit `3c1e34a62c39b12c52b90e4ab7dc2618ab340bb1`.

**Overall status: PARTIAL visual unification.** Primary Preview surfaces have the Nova presentation. Specialist scan-configuration, authentication, metadata-search, subtitle-download and alternative/classic surfaces still contain native/legacy UI. These are retained explicitly below; they must not be described as a complete whole-app reskin.

“Source reviewed” below means the entry point, layout/presenter and existing action/Back ownership were inspected. It does not prove hardware focus, keyboard, permissions or network behaviour. Every hardware-dependent case is **NOT TESTED — USER QA REQUIRED**.

## Exact remaining visual/reference deviations

- Frost is a Slate translucent surface, not live GPU blur.
- List thumbnails preserve the complete image using fit-inside; a portrait-only title has letterboxing rather than a fabricated/cropped landscape image. Missing artwork stays empty/neutral.
- HDR data is not guessed from filenames or resolution. The optional HDR column stays blank where the current database lacks reliable HDR metadata. TV audio/resolution/codec may read Mixed; incomplete byte totals use ≥ and incomplete average is omitted.
- Column reordering uses remote Left/Right on the chooser row, not drag-and-drop. Showing every optional column on one TV-width table can truncate text; defaults were designed for the supplied compact table proportions.
- Native specialised pickers retain their working adjustment mechanics inside compact panels. Scan GuidedStep screens, metadata matching, credential manager, subtitle downloader, auth and classic fallback screens are explicitly legacy/mixed. **Not a claim of full mock-up conformity for those routes.**
- Provider-controlled trailer/auth/Android keyboard/permission/external-app UI remains outside Nova's layout control.

## Settings preservation and known compatibility limits

No database schema, stored credential format or existing preference key/default was removed. These conditional controls are not fake Preview placeholders. The Preview cache filename changes to v40 because its snapshot fields changed; it is a disposable UI cache, not the media library. Existing channel sort settings stay active although Preview libraries use their own sort controls. Phone/classic preferences may remain visible where they still affect reachable alternate routes.
